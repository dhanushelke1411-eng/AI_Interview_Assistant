# AI Interview Assistant

## Overview

AI Interview Assistant is a Generative AI application that helps users prepare for job interviews by automatically generating interview questions, sample answers, and interview tips for a selected role.

The project uses a Transformer-based language model to simulate interview preparation and provide personalized guidance.

---

## Problem Statement

Job seekers often struggle to find relevant interview questions and preparation material for specific roles. This project automates interview preparation using AI-generated content.

---

## Features

- Generate role-specific interview questions
- Generate sample answers
- Provide interview preparation tips
- Interactive user input
- AI-powered content generation

---

## Technologies Used

- Python
- Hugging Face Transformers
- GPT-2
- PyTorch
- Gradio

---

## Model Used

### GPT-2

GPT-2 is a Transformer-based language model capable of generating human-like text based on prompts.

---

## Project Workflow

1. User enters job role
2. AI generates interview questions
3. AI creates sample answers
4. AI provides interview tips
5. User reviews generated content
